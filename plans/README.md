## Findings considered and rejected

- **`tar` CVEs (critical/high in `npm audit`)**: transitive dep of `bcrypt` via
  `@mapbox/node-pre-gyp`, which is a build/install-time tool only — `tar` is not
  loaded at runtime. Risk exists only during `npm install`. Run `npm audit fix`
  in `backend/` when convenient; no plan needed.
- **Dead `/events` route** (routes/events.js, events.test.js, `events` DB table):
  real tech-debt finding, not planned in this batch to keep scope tight. Worth
  doing as a follow-up — remove the route and test files; leave the DB table
  in place (dropping a production table is a separate migration decision).
- **20MB JSON body limit on `/auth` endpoints**: low severity — JSON parsing
  of a large payload is fast and the connection drops immediately after. Not
  worth a plan; can be addressed with a per-route limit if a DoS concern arises.
- **Missing `.env.example`**: plan 001 adds this as a side-effect of the
  `VITE_API_BASE` work; no separate plan needed.
